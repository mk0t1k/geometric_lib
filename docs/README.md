# Документация проекта GEOMETRIC_LIB

## Общее описание решения

Данный проект предоставляет набор функций для вычисления площадей и периметров различных геометрических фигур. Проект реализован на языке Python и состоит из нескольких модулей, каждый из которых отвечает за работу с определенной фигурой.

### Структура проекта

- `circle.py` - функции для работы с кругом
- `square.py` - функции для работы с квадратом
- `rectangle.py` - функции для работы с прямоугольником
- `triangle.py` - функции для работы с треугольником
- `tests/` - директория с unit-тестами
- `docs/` - директория с документацией

## Описание функций

### Модуль circle.py

#### `area(r)`
Вычисляет площадь круга.

**Параметры:**
- `r` (`float`): радиус круга

**Возвращаемое значение:**
- `float`: площадь круга

**Пример вызова:**
```python
result = area(5)
print(result) #78.53981633974483
```

#### `perimetr(r)`
Вычисляет длину окружности.

**Параметры:**
- `r` (`float`): радиус круга

**Возвращаемое значение:**
- `float`: длина окружности
    
**Пример вызова:**
```python
result = perimeter(5)
print(result) #31.41592653589793
```

### Модуль triangle.py

#### `area(r)`
Вычисляет площадь треугольника.

**Параметры:**
- `a` (`float`): строна треугольника(основание)
- `h` (`float`): высота треугольника, проведённая к этой стороне

**Возвращаемое значение:**
- `float`: площадь треугольника

**Пример вызова:**
```python
result = area(6, 4)
print(result) #12.0
```

#### `perimetr(r)`
Вычисляет периметр прямоугольника.

**Параметры:**
- `a` (`float`): длина первой стороны треугольника
- `b` (`float`): длина второй стороны треугольника
- `с` (`float`): длина третьей стороны треугольника

**Возвращаемое значение:**
- `float`: периметр треугольника
    
**Пример вызова:**
```python
result = perimeter(3, 4, 5)
print(result) #12.0
```

## Тестирование

### Unit-тесты

В проекте реализованы unit-тесты для проверки корректности работы всех математических функций. Тесты расположены в директории tests/ и используют стандартный модуль Python `unittest`.

### Структура тестов

- `tests/test_circle.py` - тесты для функций круга
- `tests/test_square.py` - тесты для функций квадрата
- `tests/test_rectangle.py` - тесты для функций прямоугольника
- `tests/test_triangle.py` - тесты для функций треугольника

### Запуск тестов

Для запуска всех тестов выполните команду:
``` bash
python -m unittest discover tests
```

Для запуска тестов конкретного модуля:
``` bash
python -m unittest tests.test_circle
```

### Стратегия тестирования

Тесты покрывают:

-  Позитивные сценарии с корректными входными данными
- Граничные случаи (нулевые значения)
- Проверку соответствия математическим формулам
